# THE INFINITE CANVAS

A four-page personal portfolio for a college web development practical. Built with semantic HTML5, CSS3, vanilla JavaScript and jQuery. It has no framework or build step.

## Pages

- index.html — introduction, profile image and selected work
- work.html — editorial project gallery for the Parking Automation App and Code Ranker
- resume.html — education, skills, experience, achievements and projects
- biodata.html — personal, education and contact details

## Run it

Open index.html in a browser, or serve this directory with any static HTTP server. Google Fonts, jQuery and sample Unsplash images load from the internet. Replace image URLs with local files in assets/ if desired.

## Personalize before submission

Personal details and project descriptions have been filled from the information provided. Experience and achievements are shown as none. The original sample project entries have been removed. The profile photo is stored locally at assets/aftab-profile.jpeg. Project images are illustrative stock photos.

Responsive navigation, jQuery menu behavior, smooth anchor scrolling, IntersectionObserver reveals, image hover transforms, and back-to-top control. Reduced-motion preference is respected.
